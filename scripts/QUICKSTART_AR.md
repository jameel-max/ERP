إضاءة سريعة: بعد التثبيت تقدر تفتح النظام فوراً.

**Windows**
```powershell
.\scripts\quick_start.bat
```

**Linux/macOS**
```bash
chmod +x scripts/quick_start.sh
./scripts/quick_start.sh
```

حسابا الدخول بعد التهيئة (صلاحيات كاملة متطابقة):
- ammar / ammar123
- salah / salah123

> غيّر كلمتي المرور فوراً بعد أول دخول. (لا تظهر بيانات الدخول في شاشة تسجيل الدخول.)
